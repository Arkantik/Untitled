# Veypost Technology Stack

## Frontend

- TanStack Start (Full-stack React framework)
- TanStack Router (File-based routing)
- TanStack Query (Server state management)
- React 19
- Tailwind CSS v4 (Styling)
- shadcn/ui (Component library)
- TipTap 3.x (Rich text editor)

## Backend

- NestJS 12 (API framework, Fastify adapter)
- Drizzle ORM (Database toolkit)
- BullMQ (Job queue)
- Better Auth (Authentication)
- Zod (Validation)
- Swagger / OpenAPI (API documentation)

## Infrastructure

- SQLite (Default database, zero-config)
- PostgreSQL 17 (Scaling database)
- Valkey 8 (Caching and job queue broker)
- Docker (Containerization)
- Supervisord (Process management)

## Languages

- TypeScript 7 (6.x for API due to NestJS Swagger peer dep)
- SQL

## Monorepo

- Turborepo (Build orchestration)
- pnpm (Package management)
