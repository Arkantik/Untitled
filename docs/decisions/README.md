# Decisions

Architecture decision records. One file per decision, numbered, never edited after acceptance.

A decision that changed gets a new ADR that supersedes the old one. The old file stays.
The record of what you believed and why is the valuable part, and editing it away destroys it.

Write an ADR when a choice will be expensive to reverse, when you rejected a reasonable
alternative, or when someone will otherwise ask "why is it like this" in six months.

Do not write one for a choice that has no alternative.
