# Domain context

The vocabulary of this project. One entry per concept that has a specific meaning here.

Purpose: stop the codebase from carrying three names for one idea. When a term here appears in
code, docs, tickets, or conversation, it means exactly what this file says and nothing else.

## How to use it

- Adding a concept the code does not name yet? Add it here first, then use the name everywhere.
- Finding two words for the same thing? Pick one, record it here, rename the other.
- A term that stops appearing in the code gets deleted from here. This is not an archive.
